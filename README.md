# Інформаційна система управління та відображення навчального розкладу

Вебзастосунок, у якому диспетчери складають і перевіряють розклад університету,
а студенти й викладачі бачать його актуальним — на компʼютері й на телефоні —
і вивантажують у Excel для друку.

| Частина | Стек | Де |
|---|---|---|
| Бекенд | Python, FastAPI, SQLAlchemy 2.0, PostgreSQL, Redis, openpyxl | [`backend/`](backend/README.md) |
| Фронтенд | React 19, TypeScript, Vite | [`frontend/`](frontend/README.md) |
| Документація спринтів | бізнес-аналіз, вимоги, вайрфрейми, рішення | [`docs/`](docs/) |
| Сторінка проєкту | роадмап спринтів | `index.html` |

## Швидкий старт

```bash
docker compose up -d
docker compose exec api python -m alembic upgrade head
docker compose exec api python -m scripts.seed        # права, ролі, суперадмін
docker compose exec api python -m scripts.seed_demo   # демонстраційний розклад
```

- Розклад: http://localhost:8080
- API та документація: http://localhost:8000/docs

Демо-доступи: `dispatcher@chnu.edu.ua` / `demo12345` (диспетчер),
`admin@chnu.edu.ua` / `admin12345` (суперадміністратор). Перед реальним
розгортанням паролі й `JWT_SECRET` обовʼязково змінити.

## Що вміє система

- **Довідники й календар.** Факультети, кафедри, викладачі з сумісництвом,
  групи, підгрупи, потоки, дисципліни, корпуси й аудиторії з різними
  написаннями номера, навчальні роки, семестри, автогенерація тижнів з
  парністю, свята й робочі суботи.
- **Розклад як модель, а не таблиця.** Заняття = дисципліна + тип + аудиторія
  слухачів + викладачі + аудиторії + день + пара + парність тижнів.
- **Конфлікти з поясненням.** Збіг викладача чи аудиторії блокує збереження;
  зберегти попри конфлікт можна лише з правом і письмовою причиною, яка
  потрапляє в журнал аудиту.
- **Заміни, перенесення, скасування** на конкретну дату — без зміни базового
  розкладу; студент бачить їх прямо на картці пари.
- **Перегляд без входу** — розклад групи, викладача або аудиторії на день і на
  тиждень, з підсвіткою пари, що триває зараз.
- **Excel «як для друку»** — дворядкова сітка непарний/парний тиждень,
  обʼєднання клітинок, орієнтація Landscape.

## Розробка без Docker

```bash
# бекенд
cd backend && python -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m pytest                     # 100 тестів на SQLite
.venv/bin/python -m uvicorn app.main:app --reload

# фронтенд
cd frontend && npm install
npm test                                       # 19 тестів
npm run dev                                    # http://localhost:5173
```

## Стан проєкту

Спринти 0–5 завершено: бізнес-аналіз і вимоги, технічна база, повний бекенд
MVP-1…MVP-6, публічний перегляд розкладу та кабінет диспетчера. Поза MVP
лишаються Telegram-бот і push, автогенерація розкладу, SSO/LDAP, мобільний
застосунок, інтеграція з LMS та імпорт з Excel. Детальний план — на сторінці
проєкту (`index.html`) і в `docs/`.
