# Розгортання і демонстраційні дані

**Спринт 5** · DevOps + backend. Джерела: розділи 108–109 ТЗ.

## Склад системи
| Контейнер | Образ / збірка | Порт | Роль |
|---|---|---|---|
| `db` | postgres:17-alpine | 5432 | основна БД |
| `cache` | redis:7-alpine | 6379 | кеш розкладів |
| `api` | `./backend` (FastAPI + uvicorn) | 8000 | API та бізнес-логіка |
| `web` | `./frontend` (Vite build → Nginx) | 8080 | статика SPA + проксі `/api` |

```bash
docker compose up -d                     # весь стек
docker compose exec api python -m alembic upgrade head
docker compose exec api python -m scripts.seed        # права, ролі, суперадмін
docker compose exec api python -m scripts.seed_demo   # демонстраційні дані
```

Після цього розклад відкривається на `http://localhost:8080`, документація
API — на `http://localhost:8000/docs`.

## Чому Nginx проксює API
Фронтенд звертається за відносним `/api/v1`, а Nginx перенаправляє запити на
контейнер `api`. Тому в браузер не потрапляє адреса бекенду, не потрібен CORS
у продакшні, і той самий образ працює під будь-яким доменом. У розробці те
саме робить проксі дев-сервера Vite.

## Демонстраційні дані (`scripts/seed_demo.py`)
Скрипт ідемпотентний: довідники оновлюються за натуральними ключами, заняття
демонстраційного семестру перезаписуються, демо-користувачі створюються один
раз.

- Факультет ФМІ, 4 кафедри, 7 викладачів, 9 дисциплін, 4 типи занять.
- 3 корпуси, 6 аудиторій (зокрема компʼютерні класи й спортзал) із синонімами
  написання номера.
- 5 груп із підгрупами, потік **КН-3** із трьох груп.
- 6 пар за часом від 08:30 до 19:35 і 21 заняття на тиждень.
- Точкові зміни: заміна викладача в середу, перенесення на робочу суботу,
  скасування в пʼятницю; свято 14 жовтня.

**Навчальний рік рахується від поточної дати** (з 1 липня починається
наступний), тому демо завжди показує «живий» семестр, а не минулорічний.

## Облікові записи демо
| Email | Роль | Пароль |
|---|---|---|
| `admin@chnu.edu.ua` | суперадміністратор | `SEED_ADMIN_PASSWORD`, типово `admin12345` |
| `dispatcher@chnu.edu.ua` | диспетчер розкладу | `DEMO_PASSWORD`, типово `demo12345` |
| `teacher@chnu.edu.ua` | викладач | те саме |
| `student@chnu.edu.ua` | студент | те саме |

Паролі придатні лише для демонстрації: перед будь-яким реальним розгортанням
їх треба змінити, а `JWT_SECRET` замінити на `openssl rand -hex 32`.

## Конфігурація
| Змінна | Типово | Де діє |
|---|---|---|
| `DATABASE_URL` | postgres у docker | backend |
| `REDIS_URL` | redis у docker | backend |
| `JWT_SECRET`, `ACCESS_TOKEN_TTL_MINUTES` | dev-значення, 480 хв | backend |
| `PUBLIC_SCHEDULE_ENABLED` | `true` | вмикач публічного перегляду |
| `CORS_ORIGINS` | localhost:5173, 4173, 8080 | backend |
| `VITE_API_URL`, `VITE_API_PROXY` | `/api/v1`, `localhost:8000` | frontend |
