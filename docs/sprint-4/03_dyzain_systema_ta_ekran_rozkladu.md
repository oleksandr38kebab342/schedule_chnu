# Дизайн-система та екран розкладу

**Спринт 4** · UI/UX + frontend. Джерела: вайрфрейми спринту 1, персони
«Софія» (студентка) і «Олег» (викладач), референсний макет замовника.

## Дизайн-система
Усі кольори — токени в `frontend/src/styles/tokens.css`; компоненти беруть
лише змінні, тому палітру можна змінити в одному місці. Темна тема вмикається
системним налаштуванням (`prefers-color-scheme`).

| Група токенів | Призначення |
|---|---|
| `--bg`, `--surface*`, `--border*` | полотно, картки, межі |
| `--text`, `--text-soft`, `--text-faint` | три рівні важливості тексту |
| `--ink` | темний акцент: активний день, головна кнопка |
| `--type-lec / lab / pract / elect / other` | кольори типів занять |
| `--success / warning / danger / accent` | «зараз іде», перенесення, скасування, інформація |

Типографіка: Manrope для інтерфейсу, JetBrains Mono для часу, номерів пар і
аудиторій — цифри в таблицях мають вирівнюватися по колонках.

Тип заняття визначається **кодом** з довідника (`LEC`, `LAB`, `PRACT`,
`ELECT`); невідомий код отримує нейтральний сірий, тож нові типи не ламають
вигляд.

## Екран розкладу
```
шапка: логотип · назва            [● Середа, 21 жовтня • 8-й тижд.]  Вхід
панель: [Група|Викладач|Аудиторія] Група: ▾  [Вся|1 підгр.|2 підгр.]   Тиждень: [I Непарний|II Парний]
        [Розклад на день|На весь тиждень] [Сьогодні] [←] [→]           легенда типів
        [Пн 19][Вт 20][Ср 21][Чт 22][Пт 23]
зміст:  Розклад: Середа, 21 жовтня                      КН-321 · II Парний · I семестр
        картки пар
```

**Картка пари** показує те саме, що й паперовий розклад, але в порядку
читання: номер пари → час і тип → дисципліна → викладач → аудиторія і корпус →
кому читається (потік / підгрупа).

Стани картки:
- **зараз іде** — зелена рамка, зелений номер пари, бейдж «Зараз іде»
  (рахується з локального часу пристрою, без запитів до сервера);
- **скасовано** — закреслена назва, приглушена картка, причина;
- **заміна** — червоний бейдж і підпис «заміна: ПІБ»;
- **перенесено** — жовтий бейдж і дата, куди або звідки.

## Рішення, які варто пояснити
- **Парність перемикає тиждень, а не фільтр.** У паперовому розкладі «непарний
  тиждень» — це конкретні дати. Кнопка `I Непарний / II Парний` переводить на
  сусідній тиждень, тому дата, номер тижня й перелік пар лишаються узгодженими.
- **Стан екрана — в адресі.** `?kind=group&id=5&date=2026-10-21&scope=day`
  можна надіслати однокурсникам; остання група додатково зберігається в
  `localStorage`, щоб наступного разу відкрилася одразу.
- **Вихідні зʼявляються за потреби.** Стрічка днів показує Пн–Пт, а Сб/Нд — лише
  коли там справді є пара.
- **Телефон.** На вузькому екрані фільтри переносяться, стрічка днів гортається
  горизонтально, аудиторія переїжджає під назву дисципліни.
- **Доступність.** Перемикачі — справжні `button` з `aria-pressed`, стрічка днів
  позначена `aria-current`, фокус видно завжди, анімація вимикається за
  `prefers-reduced-motion`.
