# User Personas та User Roles

**Спринт 1** · БА + UI/UX (+ PM, тімліди).
Персони — **робочі гіпотези** на основі ТЗ, а не результати реальних опитувань; перевірити на інтерв'ю та з диспетчерами. Імена вигадані.

## Персони
### Марина, диспетчер розкладу факультету (основна)
- **Ціль:** до початку семестру зібрати розклад без конфліктів і вивантажити його в Excel для друку.
- **Біль:** правки в Excel ламають чужі клітинки; конфлікти видно лише після розсилки; аудиторії пишуть по-різному.
- **Потреби:** підказка про конфлікт одразу, швидке копіювання дня/тижня, експорт для кількох груп.
- **Успіх:** нуль «двійних» аудиторій, розклад готовий за кілька днів.

### Олег, викладач кафедри
- **Ціль:** знати, де і коли його пари, включно із заміною й перенесенням.
- **Біль:** дізнається про зміни випадково.
- **Потреби:** особистий розклад на тиждень, позначення змін, швидкий доступ з телефона.

### Софія, студентка 2 курсу
- **Ціль:** за 5 секунд побачити «Сьогодні» для своєї групи/підгрупи.
- **Біль:** незрозуміло, парний чи непарний тиждень; таблиця на телефоні нечитабельна.
- **Потреби:** картки пар з часом, викладачем і аудиторією; вказівка типу тижня.

### Ірина, адміністратор кафедри
- **Ціль:** підтримувати дані кафедри (викладачі, дисципліни, групи) актуальними.
- **Біль:** сумісники й викладачі з інших кафедр «не вміщаються» в одну прив'язку.
- **Потреби:** зв'язки викладач↔кафедра з датами дії, права лише на свою кафедру.

## User Roles (за розділами 3–4 ТЗ)
| Роль | Ключові права (permissions) | Область |
|---|---|---|
| Суперадміністратор | усі, вкл. `users.manage`, `roles.manage`, `settings.manage`, `audit.view` | вся система |
| Головний адміністратор | усі навчальні, без частини системних налаштувань | вся навчальна структура |
| Адміністратор факультету | `*.manage` довідників факультету, `schedule.*` | свій факультет |
| Адміністратор кафедри | `teacher/group/room.view`, `department.manage` | своя кафедра |
| Диспетчер розкладу | `schedule.create/edit/delete/move/cancel/override_conflict/import/export` | за призначенням |
| Викладач | `schedule.view`, `teacher.view` (свої дані) | особистий розклад |
| Студент | `schedule.view` | своя група / підгрупа / потік |

Перевірка прав — лише на backend.
