# Frontend — перегляд і редагування розкладу

React 19 + TypeScript + Vite. Два режими в одному застосунку:

- **публічний перегляд** (`/`) — розклад групи, викладача або аудиторії на день
  і на тиждень, без входу;
- **кабінет** (`/dispatcher`, `/export`, `/audit`) — редагування занять з
  перевіркою конфліктів, заміни й перенесення, експорт Excel, журнал аудиту.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173, /api проксюється на :8000
```

Бекенд має працювати на `http://localhost:8000` (див. `../backend/README.md`),
а база — бути наповненою демо-даними:

```bash
cd ../backend
python -m scripts.seed && python -m scripts.seed_demo
```

## Команди

| Команда | Що робить |
|---|---|
| `npm run dev` | дев-сервер з HMR і проксі на API |
| `npm run build` | `tsc -b` + продакшн-збірка у `dist/` |
| `npm run preview` | перегляд зібраного `dist/` |
| `npm test` | vitest: чисті функції, картка пари, сторінка розкладу |
| `npm run lint` | oxlint |

## Налаштування

| Змінна | Типово | Призначення |
|---|---|---|
| `VITE_API_URL` | `/api/v1` | база API; у контейнері лишається відносною, бо Nginx проксює `/api` |
| `VITE_API_PROXY` | `http://localhost:8000` | куди дев-сервер шле `/api` |

## Структура

```
src/
  api/        типи відповідей, fetch-клієнт, перелік ендпоінтів
  auth/       контекст автентифікації (JWT у localStorage)
  components/ Layout, LessonCard, WeekGrid, DayStrip, форми, Modal
  lib/        дати, представлення занять, тексти конфліктів (чисті функції)
  pages/      розклад, вхід, кабінет диспетчера, експорт, аудит
  styles/     токени теми (світла + темна) і стилі застосунку
```

## Рішення, які варто знати

- **Стан екрана — в адресі.** Група, дата, режим і підгрупа живуть у
  query-параметрах, тому посиланням можна поділитися («ось наш четвер»).
- **Парність — властивість тижня.** Перемикач `I Непарний / II Парний` не
  фільтрує заняття, а переводить на сусідній тиждень: так само, як у
  паперовому розкладі.
- **Права перевіряє бекенд.** Фронтенд за `permissions` лише ховає кнопки;
  кожен запит усе одно проходить перевірку на сервері.
- **Дати рахуються в локальному часі.** `toISODate` замість `toISOString`,
  інакше о 23:30 користувач побачив би завтрашній день.
- **Теми.** Кольори оголошені токенами в `styles/tokens.css`; темна тема
  вмикається системним налаштуванням.
